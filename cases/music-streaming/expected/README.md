# Music Streaming expected models

The Document and U-Schema XMI files provide expected-model artifacts for comparison with the [generated schemas](../generated/). They are intermediate/target schema models, not expected reconstructed relational schemas.

For round-trip reconstruction, compare the returned relational schema with its original relational input; see [round-trip](../../../experiments/roundtrip/). The evaluation used EMF Compare and visual inspection. File origins and identities are documented in `provenance.json`; no new model comparison was run during package preparation.
