# music-streaming recovered expected models

This folder contains the Document and U-Schema expected XMI files recovered from the group OneDrive folder `roundtrip/Roundtrip-expected-models`. They describe intermediate U-Schema and target Document models, not reconstructed relational schemas. Filenames, model bytes and namespace URIs are preserved.

These files are included as recovered expected-model artifacts, distinct from the [generated candidates](../generated/). Their presence does not establish equality with generated outputs, independent derivation, or conformance with a particular metamodel/runtime version.

XML parsing and byte-for-byte copy integrity have been checked. No model comparison, transformation, or EMF validation was performed during packaging. Provenance and SHA-256 hashes are recorded in the adjacent files.
