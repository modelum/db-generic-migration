# Trace updater

[OrionTraceChanger](../source-projects/OrionTraceChanger/) implements renaming, attribute deletion and Aggregate-to-Reference conversion with updates to the transformation trace. [Trace](../source-projects/Trace/) supplies trace persistence.

See the [Music Service adaptation experiment](../../experiments/trace-adaptation/) for the predefined scenario, inputs and outputs. Build dependencies are listed in [DEPENDENCIES.md](../source-projects/DEPENDENCIES.md).
