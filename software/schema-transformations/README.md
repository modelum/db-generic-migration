# Schema transformations

The selected implementation sources are included unchanged in [DataMigration](../source-projects/DataMigration/) for the forward chain and [RoundTripV2](../source-projects/RoundTripV2/) for forward/reverse schema reconstruction. Trace management is in [Trace](../source-projects/Trace/).

These snapshots have not been compiled or validated as a combined release. See the [dependency map](../source-projects/DEPENDENCIES.md), [provenance](../source-projects/provenance.json) and [metamodel compatibility note](../metamodels/COMPATIBILITY.txt). Original supporting models remain versioned examples, not validated final experimental outputs.
